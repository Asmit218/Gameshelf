# GAMESHELF

GAMESHELF is an online platform where players compete in logic-based **mind games** against friends or random opponents. The goal of the platform is to create a competitive environment where players can test their reasoning and strategy skills.

Players can challenge others, wager in-platform points called **BIOS**, climb the **leaderboards**, and track their performance through detailed **statistics pages**. New games will be added regularly to expand the platform.

---

## Features

- Play **mind and logic games** online
- Challenge **friends or random players**
- **BIOS point betting system** for competitive matches
- **Global leaderboard** to track top players
- **Player statistics dashboard**
- **Game rooms** for multiplayer matches
- Continuous addition of **new games**

## Gameplay Concept

Players can select a game and compete against:

- **Friends**
- **Random players**

Matches can optionally include **BIOS point wagers**, adding a competitive layer to gameplay. Players earn BIOS by winning games and climb the **leaderboard rankings**.
